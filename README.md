# Нейронная сеть на C++
В данном проекте реализована нейронная сеть на языке C++, предназначенная для определения принадлежности точек на плоскости к одному из двух классов: 0 или 1.

Проект содержит три варианта расположения точек. Общие функции и класс нейронной сети вынесены в отдельные файлы, а запуск всех вариантов выполняется через `main.cpp.`

## Варианты расположения точек
### 1. Два квадрата 
Точки, расположенные в двух квадратах с разными центрами.
### 2. Круг 
Точки, расположенные внутри и вне круга.
### 3. Синус
Точки, расположенные внутри и вне синусоидальной полосы.

## Структура проекта
- include/data.h — объявления классов `Point`, `Norm` и функций для работы с данными.
- src/data.cpp — чтение точек, нормализация и разделение данных на выборки.
- include/generator.h — объявления функций генерации точек.
- src/generator.cpp — реализация трёх вариантов генерации точек.
- include/neuralnetwork.h — объявление класса `Neuralnetwork` и его методов.
- src/neuralnetwork.cpp — реализация обучения, предсказания и других методов нейронной сети.
- main.cpp — выбор варианта, создание и обучение нейронной сети.
- CMakeLists.txt — сборка программы.

## Как работает программа

1. Пользователь выбирает вариант расположения точек и вводит их количество.
2. Программа случайным образом генерирует точки с координатами `x, y` и меткой класса 0 либо 1.
3. Данные перемешиваются и делятся на две выборки: обучающую (80%) и валидационную (20%).
4. Координаты точек нормализуются по минимуму и максимуму обучающей выборки перед подачей в нейронную сеть.
5. Нейронная сеть обучается на обучающей выборке, а после каждой эпохи оценивается точность на валидационной выборке.
6. Программа сохраняет предсказанные классы в файл для построения графика.

## Параметры нейронной сети

### Архитектура: 
2 входа ( x, y ), 2 скрытых слоя по 8 нейронов каждый, 1 выход.
### Функция активации : 
Cигмоида.
### Обучение:
Обучение происходит методом обратного распространения ошибки. После обработки каждой точки веса нейронной сети обновляются с помощью антиградиента.

##Запуск программы
### 1. Компиляция
Откройте терминал в папке проекта, где находятся `main.cpp`, `include` и `src`, и выполните:
```bash
g++ -std=c++17 -Wall -Iinclude main.cpp src/data.cpp src/generator.cpp src/neuralnetwork.cpp -o app.exe`
```
При наличии CMake можно также собрать проект командами:
```bash
cmake -S . -B build
cmake --build build
```

### 2. Запуск
В Windows (PowerShell) после компиляции через `g++`:
```bash
.\app.exe
```
После запуска выберите вариант: 1 — два квадрата, 2 — круг, 3 — синус. Затем введите количество точек, например `10000` (не менее 10).

### 3. Построение графика

После завершения программы в текущей папке создаются файлы:

point.txt - сгенерированные точки: x y исходный класс.
<br>
pointnew.txt - те же точки, но класс предсказан нейронной сетью.
<br>
point.plt - скрипт для Gnuplot, который строит график по pointnew.txt.

Чтобы открыть график:
<br>
gnuplot -persist point.plt

## Что можно менять

Можно изменять количество точек, число скрытых слоёв, скорость обучения и количество эпох. Результаты разных запусков могут отличаться, поскольку точки генерируются случайным образом.
