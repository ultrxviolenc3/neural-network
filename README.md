# Нейронная сеть на С++
В данном проекте реализована нейронная сеть на языке С++, предназначенная для определения принадлежности точек на плоскости к одному из двух классов: 0 или 1.

Проект состоит из трех программ с разными вариантами расположения точек.
## Программы

### `neyro.cpp` 
Точки, расположенные в двух квадратах с разными центрами.

### `new.cpp`
Точки, расположенные внутри и вне круга.

### `ns.cpp`
Точки, расположенные внутри и вне синусоидальной полосы.

<br>

Каждый файл `.cpp` - это самостоятельная программа, которую нужно запускать отдельно.

## Как работает программа

1. Пользователь вводит количество точек.
2. Программа случайным образом генерирует точки с координатами `x` , `y` и с меткой класса `0` либо `1`.
3. Данные перемешиваются и делятся на 2 выборки: обучающую (80%) и валидационную (20%).
4. Сгенерированные точки нормализуются по минимуму и максимуму обучающей выборки.
5. Нейронная сеть обучается на обучающей выборке, а после каждой эпохи оценивается точность на валидационной выборке.
6. Программа запоминает предсказанные классы в файл для построения графика.

## Параметры нейронной сети

### Архитектура: 
2 входа ( `x`, `y` ), 2 скрытых слоя по 8 нейронов каждый, 1 выход.
### Функция активации : 
Cигмоида.
### Обучение:
Обучение происходит методом обратного распространения ошибки. После обработки каждой точки веса нейронной сети обновляются с помощью антиградиента.

## Запуск программы

 ### 1. Компиляция
Откройте терминал в папке с исходными файлами и скомпилируйте нужную программу:
<br>
`g++ neyro.cpp -o neyro`
<br>
`g++ new.cpp -o new`
<br>
`g++ ns.cpp -o ns`

### 2. Запуск
В Windows (PowerShell):
<br>
`.\neyro.exe`
<br>
`.\new.exe`
<br>
`.\ns.exe`

После запуска программы введите количество точек к примеру `10000`. В терминале отобразятся номер эпохи и `valid accuracy` - часть верно классифицированных точек.

### 3. Построение графика

После завершения программы в текущей папке создаются файлы:

`point.txt` - сгенерированные точки: `x` `y` `исходный класс`.
<br>
`pointnew.txt` - те же точки, но класс предсказан нейронной сетью.
<br>
`point.plt` - скрипт для Gnuplot, который строит график по `pointnew.txt`.

Чтобы открыть график:
<br>
`gnuplot -persist point.plt`

## Что можно менять

Можно изменять количество точек, число скрытых слоёв, скорость обучения и количество эпох. Результаты разных запусков могут отличаться, поскольку точки генерируются случайным образом.
